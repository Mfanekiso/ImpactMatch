# Expo HAS CHANGED

This project uses Expo SDK 54. Expo APIs differ from older versions, so do not rely on memory for them.

## When to read the docs

- Before writing or changing code that uses Expo APIs (`expo-*` packages, Expo Router, `app.json`/`app.config.*`, EAS), read the versioned docs: https://docs.expo.dev/versions/v54.0.0/
- If that URL redirects to a different SDK version or can't be reached, don't stop. Use the installed package's types and README in `node_modules/` as the source of truth, and say which source you used.

## When you can skip the docs

- Changes that don't touch Expo APIs (plain React/React Native logic, state, styling, text, status or UI fixes, Firebase logic) don't need a docs lookup. Proceed directly.
